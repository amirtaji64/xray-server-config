# Xray VPN server for Windows (VLESS + WebSocket + Cloudflare + WARP)

سرور VPN روی **ویندوز سرور خالی** با **یک دستور**، همراه با **پنل مدیریت کاربران** (حجم، تعداد دستگاه، تاریخ انقضا).

```
کلاینت‌ها (v2rayN / موبایل)
   │  VLESS + WS + TLS  (fingerprint: firefox)
   ▼
Cloudflare  (ساب‌دامنه، ابر نارنجی، SSL: Flexible)
   │  HTTP پورت 80  + هدر IP واقعی کاربر
   ▼
ویندوز سرور ── 3x-ui (پنل) ── Xray
   ├── سایت‌های گوگل (Gemini, AI Studio, YouTube, ...) ──► Cloudflare WARP
   └── بقیه ترافیک ──► مستقیم از IP سرور
```

## نصب (روش پیشنهادی: با پنل کاربران)

روی سرور، **PowerShell را با Run as Administrator** باز کنید (نه CMD؛ ابتدای خط باید `PS` باشد) و فقط `<UUID>` و `<DOMAIN>` را عوض کنید:

```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; & ([scriptblock]::Create((irm https://raw.githubusercontent.com/amirtaji64/xray-server-config/main/install-panel.ps1))) -Uuid <UUID> -Domain <DOMAIN>
```

- `<UUID>`: همان UUID فعلی کلاینت‌ها (اکانت `owner`، بدون محدودیت). **همیشه همان قبلی را بدهید** تا کانفیگ کسی عوض نشود.
- `<DOMAIN>`: ساب‌دامنه‌ای که در Cloudflare به سرور اشاره می‌کند.

اسکریپت خودش این‌ها را انجام می‌دهد (دوباره اجرا کردنش هم بی‌خطر است):

1. آخرین نسخه **3x-ui** و آخرین نسخه **Xray-core** را در `C:\x-ui` نصب می‌کند.
2. نام کاربری، رمز و آدرس **تصادفی** برای پنل می‌سازد (در `C:\x-ui\panel-login.txt`، فقط ادمین).
3. پنل را با روشن شدن ویندوز اجرا می‌کند + **نگهبان**: اگر بسته شود، ظرف ۱ دقیقه خودش دوباره بالا می‌آید.
4. ورودی VLESS روی پورت 80 با همان مسیر قبلی + اکانت `owner` با UUID شما.
5. WARP رایگان برای سایت‌های گوگل (Gemini از نظر گوگل «آمریکا» دیده می‌شود).
6. Xray قدیمی (اگر از `install.ps1` نصب شده بود) را خاموش می‌کند و چک می‌کند پنل روی پورت 80 جواب می‌دهد.
7. **iplimit.ps1** را نصب می‌کند: اجرای واقعی «محدودیت تعداد دستگاه» + پایش سلامت WARP (پایین توضیح داده شده).

آخر کار، **آدرس پنل، نام کاربری و رمز** و لینک اکانت owner را چاپ می‌کند.

> پورت پنل (2053) روی اینترنت **بسته** است. پنل را فقط وقتی **به همین VPN وصل هستید** باز کنید: `http://<IP-سرور>:2053/<مسیر>/`. اگر VPN قطع بود: با RDP وارد سرور شوید و `http://localhost:2053/<مسیر>/` را باز کنید.

### نصب ساده (بدون پنل، یک کاربر)

اگر مدیریت کاربر لازم ندارید: همان دستور بالا با `install.ps1` به جای `install-panel.ps1`. Xray در `C:\Xray` با تسک `Xray`.

## ساخت اکانت برای همکاران

پنل ← **Inbounds** ← ردیف `vless-ws-cloudflare` ← **Add Client**:

| فیلد | مثال | توضیح |
|---|---|---|
| Email | `ali` | اسم یکتای اکانت |
| Limit IP | `2` | حداکثر دستگاه هم‌زمان (یکی بیشتر از نیاز بگذارید؛ عوض کردن وای‌فای/دیتا چند دقیقه دو دستگاه حساب می‌شود) |
| Total GB | `1` | حجم |
| Expiry / Auto renewal | ماهانه، روز ۱ | تمدید و صفر شدن خودکار حجم هر ماه |
| Comment | `علی رضایی، 0912...، حسابداری` | مشخصات صاحب اکانت |

بعد از ذخیره، از منوی همان کاربر **QR / لینک** را بگیرید و بفرستید. در لینک، اگر `fp` نبود، `&fp=firefox` اضافه کنید.

با رسیدن حجم یا تاریخ، اکانت خودکار غیرفعال می‌شود. مصرف و آنلاین بودن هر نفر در پنل دیده می‌شود.

## محدودیت تعداد دستگاه (Limit IP) روی ویندوز

3x-ui روی ویندوز دستگاه اضافه را فقط ۰.۱ ثانیه قطع می‌کند (عملاً بی‌اثر؛ روی لینوکس با fail2ban کار می‌کند). برای همین `iplimit.ps1` (تسک `3x-ui-iplimit`) اضافه شده:

- هر ۵ ثانیه IPهای آنلاین هر اکانت را از Xray می‌گیرد (IP واقعی کاربر از Cloudflare؛ `CF-Connecting-IP` / `X-Forwarded-For`).
- اگر تعداد دستگاه‌های ۶۰ ثانیه اخیر از Limit IP بیشتر شد، **جدیدترین** دستگاه‌ها را ۳ دقیقه مسدود می‌کند (قانون مسیریابی داخل Xray؛ بقیه دستگاه‌ها و کاربران اصلاً متوجه نمی‌شوند).
- لاگ: `C:\x-ui\log\iplimit.log`

تست شده: اکانت ۲ دستگاهه با ۳ دستگاه هم‌زمان ← دستگاه سوم ظرف ~۱۰ ثانیه قطع شد، دو دستگاه دیگر و اکانت owner بدون قطعی.

**پایش سلامت WARP:** Xray گاهی بعد از ری‌استارت، WARP را بالا نمی‌آورد (همه سایت‌های گوگل قطع می‌شوند). همین اسکریپت هر دقیقه گوگل را از مسیر WARP تست می‌کند و بعد از ۲ شکست پشت‌سرهم Xray را ری‌استارت می‌کند (تست شده).

## ظرفیت سرور (اندازه‌گیری روی VPS آمریکا: 2 vCPU Ryzen 9 7950X، 4GB RAM)

| مورد | مقدار |
|---|---|
| دانلود سرور | ~۲۸۰ تا ۴۳۰ Mbps |
| آپلود سرور (= سقف مجموع دانلود همه کاربران) | ~۱۱۰ تا ۱۶۰ Mbps |
| سرعت هر کاربر از ایران (محدودیت مسیر ایران/Cloudflare) | ~۱ تا ۱.۵ مگابایت بر ثانیه (~۱۰ Mbps) |
| CPU زیر بار | ~۱٪؛ گلوگاه نیست |
| رم پنل + Xray | ~۱۰۰ مگابایت |

**برآورد:** گلوگاه، آپلود سرور است (~۱۳۰ Mbps):
- **دانلود/ویدیو سنگین هم‌زمان با سرعت کامل:** حدود **۱۲ تا ۱۵ نفر**.
- **استفاده معمولی هم‌زمان** (وب، اینستاگرام، پیام‌رسان؛ میانگین ۱ تا ۲ Mbps): حدود **۶۰ تا ۸۰ دستگاه**.
- **پیشنهاد:** تا حدود **۳۰ تا ۴۰ اکانت** با Limit IP = 2 بدون افت محسوس. بیشتر از آن، مصرف واقعی را چند روز در پنل ببینید.
- سقف ترافیک ماهانه پلن VPS را هم از ارائه‌دهنده چک کنید؛ مجموع حجم اکانت‌ها از آن بیشتر نشود.

| فیلد | مقدار |

## مدیریت روی سرور

همه چیز Scheduled Task است، **نه سرویس ویندوز** (`Start-Service` کار نمی‌کند).

| کار | دستور (PowerShell ادمین) |
|---|---|
| وضعیت | `Get-Process 3x-ui,xray-windows-amd64` و `Get-ScheduledTask 3x-ui*` |
| ری‌استارت Xray | پنل ← Xray ← Restart، یا: `Stop-Process -Name xray-windows-amd64 -Force` (پنل خودش بالا می‌آورد) |
| ری‌استارت پنل | `Stop-Process -Name 3x-ui -Force` (نگهبان ظرف ۱ دقیقه اجرا می‌کند) |
| رمز پنل | `Get-Content C:\x-ui\panel-login.txt` |
| به‌روزرسانی | همان دستور نصب + `-UpdatePanel` (Xray-core همیشه خودکار به‌روز می‌شود) |
| لاگ‌ها | `C:\x-ui\log\3xui.log`، `C:\x-ui\log\iplimit.log` |
| بکاپ کاربران | فایل `C:\x-ui\x-ui.db` |

**برگشت به Xray ساده (بدون پنل):**

```powershell
'3x-ui','3x-ui-iplimit' | % { Disable-ScheduledTask $_ | Out-Null }; Get-Process 3x-ui,xray-windows-amd64 -EA 0 | Stop-Process -Force
Get-CimInstance Win32_Process -Filter "Name='powershell.exe'" | ? CommandLine -match 'iplimit' | % { Stop-Process -Id $_.ProcessId -Force }
Enable-ScheduledTask Xray; Start-ScheduledTask Xray
```

## خطاهای رایج

| خطا | علت و راه‌حل |
|---|---|
| `is not recognized as an internal or external command` | دستور را در CMD زده‌اید. اول `powershell` بنویسید. |
| کلاینت خطای `-1` | UUID کلاینت با اکانت‌های پنل یکی نیست. |
| `Port 80 is used by ...` | برنامه دیگری (مثلاً IIS) پورت را گرفته؛ پیام خطا دستور توقفش را می‌گوید. |
| Gemini «کشور پشتیبانی نمی‌شود» | از نظر گوگل IP خروجی در کشور تحریمی است. روی سرورهای Hostkey آلمان، WARP «روسیه» دیده می‌شد؛ روی سرور آمریکا «آمریکا». |
| سایت‌های گوگل باز نمی‌شوند | پایش WARP ظرف ~۲ دقیقه خودش Xray را ری‌استارت می‌کند؛ لاگ `iplimit.log`. |
